Approaching for Manipulation: Robot Termination Pose Generation via Active Object Detection and Task-oriented Logical Reasoning
(Accepted by Expert Systems with Applications, 2026)

Yuhao Wang, Guohui Tian, Xuyang Shao



Abstract

Approaching objects for manipulation (AM) presents a critical challenge in robotics, requiring autonomous navigation to viewpoints that actively facilitate downstream manipulation. Unlike conventional tasks assuming fixed viewpoints, AM demands a semantic understanding of the scene to reason about where to interact and how to position the robot relative to task constraints. However, existing methods predominantly prioritize approach efficiency, often neglecting the intricate coupling between object affordances and specific task requirements. To bridge this gap, we propose a two-stage framework integrating Active Object Detection (AOD) with task-oriented logical reasoning. The AOD stage executes coarse navigation to localize the target, while the subsequent reasoning stage fine-tunes the viewpoint to ensure a manipulation-ready pose. Specifically, we develop a spatial attention-based Dueling DQN to encode multimodal features across objects, actions, and scenes, enhanced by a novel dynamic reward function that balances approach speed with alignment precision. Furthermore, we introduce a Dempster-Shafer theory-based framework to infer optimal pose adjustments by fusing evidence from object affordances and service tasks. This inference guides a Large Multimodal Model (LMM) to align the robot's lateral position with the target manipulable region. To address geometric constraints imposed by supporting objects, we further leverage the LMM to refine the terminal viewpoint, ensuring collision-free positioning. Extensive experiments on the Active Vision Dataset and real-world deployment on a TIAGo robot demonstrate that our method achieves human-like approaching behaviors, significantly outperforming LMM-based baselines while achieving performance comparable to user-controlled operations.
